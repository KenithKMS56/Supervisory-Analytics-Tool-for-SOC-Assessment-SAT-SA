# PS SIH26157 Traceability Matrix

> **Supervisory Notice:** *Indicators requiring supervisory review; not a compliance determination.*
> All results cited here come from **synthetic data only; a real-data pilot is pending.**

One row per requirement of problem statement SIH26157: its 17 functional requirements (F), 6
deployment requirements (D), the out-of-scope items (O) and two further statements (S). The
requirement text is quoted as recorded in `docs/legal_traceability.md` Section 3, which also
gives the statutory context of each group and what needs legal review. Products named in a row
(Splunk, ServiceNow, TheHive) are this project's choice; the problem statement names none.

Every file and test named in the Code and Test columns exists: `tests/test_traceability_links.py`
reads this table and checks each path, and each `file.py::test_name`, against the repository.
The status at the start of the last column says how far the evidence goes.
